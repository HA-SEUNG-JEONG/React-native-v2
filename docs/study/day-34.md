# Day 34 · 11/26 (목) — 예비
> **오늘의 핵심**: 11/26 예비일과 11/27 버퍼는 밀린 미션, 열린 항목, 재복습을 비우는 날이며, 둘 다 비면 P8을 하루 앞당겨 시작해도 된다.

**시작 상태**: 새 미션은 없다. [Day 33](./day-33.md)에서 정리한 열린 항목 목록(미검증 📱 포함)과 재복습 일정이 출발점이다. [Day 30](./day-30.md)에서 넘어온 Notification 권한 함수 통합(순서 5번)이나 Day 33에서 넘어온 P8 읽기가 남았다면 11/26에 먼저 한다.


## 오늘 할 일 (총 90분)
- [ ] 00~05 시작 의식: `git status --short --branch`, `nvm use 22.21.1`, 어제 "내일 할 일" 확인
- [ ] 05~55 마무리: 밀린 미션과 넘어온 항목을 끝낸다 → 확인: 해당 미션 끝 조건 3개, 검증 4종 통과
- [ ] 55~75 정리: 열린 항목 목록(미검증 📱)에서 오늘 닫을 수 있는 것을 닫고, 못 닫는 것은 사유를 적는다
- [ ] 75~90 기록: 해당 `docs/improve/reviews/N-N.md`와 내일 할 일 한 줄
